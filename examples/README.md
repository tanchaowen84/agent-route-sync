# 可选配置参考

四套完整模板展示一种实现，不是安装器，也不是 Agent 接入的必经步骤。**实际目标与边界以 [AGENTS](../AGENTS.md)、[CLIENTS](../docs/CLIENTS.md) 和 [DNS-WEBRTC](../docs/DNS-WEBRTC.md) 为准。** Agent 可以按实际版本使用其他实现。

## 历史验证与能力要求

以下是截至 2026-11-02 整理的既有记录，不表示本次新增实机验证。验证版本不是整个项目的版本门槛；功能下限也不保证所有更高版本继续接受相同字段。

| 示例 | 历史记录 / 使用前需核实 |
| --- | --- |
| [Mihomo](full/mihomo.yaml) | 1.19.32：配置检查、隔离实例规则加载、DNS 与分流命中 |
| [sing-box](full/sing-box.json) | 1.14.4：配置检查、隔离实例 DNS 答案筛选与分流命中；模板使用 1.14.0 引入的 DNS 能力，其他版本须核对是否支持相应语义 |
| [Surge](full/surge.conf) | 历史仅做配置检查；模板的 `[Host]` 规则集引用要求 Mac 5.10.0+，这是功能下限，不是全版本验证声明 |
| [Shadowrocket](full/shadowrocket.conf) | 仅做文本结构检查，未在实体 iOS 验证；部分字段依据来自社区资料，须按实际 App 能力确认 |

这些模板的历史检查不代表目标设备的 TUN、真实 DNS/WebRTC、IPv6、长期负载、重启或订阅持久化已通过。

## 参考方式

- 先识别实际核心与浏览器版本，查询对应官方文档、迁移说明、帮助或 Schema。版本升级可能弃用字段，不能把“最低版本以上”理解为永久兼容。
- 只合并必要部分，保留节点、订阅、用户例外与现有有效设置；不得把模板整份覆盖到用户配置。模板中的策略名称、解析器、引导和本地 DNS 前提都需现场核实。
- 必须保持规则语义、DNS 目标和可恢复性。不能为了沿用示例而升级/降级软件、放宽目标或丢弃用户例外。
- 使用实际版本的检查方式核验候选，再在授权目标中逐项验证。没有充分证据就说明限制，不将 CI 结果当作设备验收。
